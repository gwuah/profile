# Kwaw · engineering profile

A static two-page site. No build step and no server code.

- `index.html`: overview of my public GitHub work
- `flyio.html`: my Fly.io contribution record

To host on GitHub Pages: push these files to a repository, then in Settings > Pages choose
"Deploy from a branch", the branch, and the root folder. Netlify, Vercel and Cloudflare Pages
also work: point them at this folder with no build command.
